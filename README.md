                    A Faster Video Object Detection Algorithm

ILABOT (I Looked A Bunch Of Times) aims to be a video object detection algorithm 
specifically designed for projects requiring high framerate cameras, such as 
photography, highway speeding cameras, or any project where accuracy is just as
important as seeing exactly when a fast-moving object enters and exits the frame.
The project is a very early work in progress, and is not complete yet.
